# 小车忙忙镇：玩法与交互方案

## 核心体验

“我开着自己的小车，帮朋友做一件小事。”每轮只突出一个目的地和一个动作；通过自动驾驶、温暖提示与贴纸收集给孩子自主完成的成就感。无倒计时、生命值、排行或惩罚。

## 场景结构

固定正交斜俯视的草地玩具岛，规则道路连接六个地点：薄荷车库、珊瑚面包店、黄色花房、消防站、树荫公园和蓝白洗车屋。树木、栅栏、斑马线与小花组成清晰地标。小车保持醒目的暖色；目的地有图标标记与地面提示。

## 三个任务

| 任务 | 第一步 | 第二步 | 正向反馈 |
| --- | --- | --- | --- |
| 送面包 | 去面包店，装上面包 | 去公园，分享面包 | 面包贴纸、彩纸和鼓励 |
| 送小花 | 去花房，装上小花 | 去消防站，种下小花 | 小花贴纸、彩纸和鼓励 |
| 洗洗车 | 去洗车屋，开始洗车 | 回车库，停好小车 | 泡泡贴纸、彩纸和鼓励 |

每项任务两步，中途没有失败。到其他地点不会扣分，只需再点目的地。已经获得的贴纸不会重复计数，仍可重复体验任务。

## 交互与界面

- 顶部：游戏标识、小镇/贴纸册切换、声音开关、帮助。
- 左侧：当前任务插图、两个步骤、简单提示；可选择其他任务。
- 中间：大面积 3D 小镇，点击地标或高亮目的地图标可自动行驶。
- 底部：醒目的“出发”或“帮忙”按钮、暂停，以及轻量鼓励文案。
- 到站后显示当前动作按钮；动作完成给短反馈，再点“继续”或“下个任务”。
- 贴纸册展示三枚贴纸与收集进度；帮助用三幅图示说明点击、开车和帮忙。
- 主要控件至少 56 CSS 像素，避免双摇杆、拖拽相机和依赖文字的小目标。内置本地中文提示语增强引导，声音不可用时仍能靠图标和按钮完成。
- 系统减少动态效果偏好下减少装饰动画；暂停、切后台或弹窗时暂停驾驶。

## 本轮边界

这是可运行的交互原型。暂无真实交通模拟、复杂碰撞、账号、多人、后端或购买入口。更复杂的动作动画和儿童实测反馈可在下一轮优化；真实设备性能不以云端帧率代替。
