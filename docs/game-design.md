# 小车忙忙镇 V2 玩法

核心循环是「听与看 → 主动收起任务 → 选合适的小车 → 回忆并装货 → 自己选地点 → 选择交货 → 收到具体反馈」。每局三次委托，完成后可以休息或换一个新小镇。

## 记忆与难度

轻松出发：一种物品、一个地点，数量1–2，货架两三个选项，无突发事件。记忆小司机：两种物品和两个地点，不要求先后。勇敢小队长：三个步骤、最多两个地点，需要按顺序完成。难度由设置明确选择，不根据孩子错误次数偷偷升级。

任务卡使用物品与地点图形、数量、中文语音。主动点“记住了”才收起，没有记忆倒计时。此后货架不标正确答案，地图不提供正确目的地箭头；“再看”和“再听”不消耗奖励。声音由本地有限词组拼接完整任务，运行时不联网合成。

六种车辆共享点击自动驾驶：小货车、大卡车有不同容量；冷藏、洒水、维修、小巴分别支持冷藏物品、清水、工具和乘客。早期只提供少量车型候选。物品包括面包、苹果、牛奶、鲜花、清水、工具、包裹、图书、种子、冰激凌、皮球和小乘客。

## 随机小镇

同一局地点与道路固定，换局重新取种子。三种主题沿用稳定的地点名称和图标；七个地点随机分配到连通路网，边和路网间距变化。正交相机随车轻柔移动，可一键看全镇，不需要拖动或旋转。装饰随机与任务随机分离。

## 遇到变化

入门没有事件；其余每局最多一次，在一次正确配送后发生。

- 修路：路障真正封住一条边，可以沿替代路线走，或请工人开放便道。
- 货架补货：选择备用箱，或去汽车工坊取货。工坊既能成为临时补给点，也仍可交货。
- 载量变化：仅当还有多件要送才触发。加小拖车可以一起带走；选择分趟则保留下一件，其余安全暂存仓库，之后可取回。
- 轮胎维修：点三次打气看进度，或请朋友一次修好；求助不受惩罚。

事件不能清除原任务或产生不可达地点。不计时、不扣分、没有生命值。错误交货保留物品，孩子可以改路、回仓、重听或主动寻求帮助。奖励记录帮忙次数，历史V1贴纸保存为旧版回忆。

## 表现与资源

明亮低多边形城镇、可复用GLB，Kenney车与原创模型保持玩具比例；图标直接画进官方GUI。起步、停车、装货、配送、天气和按键使用有上限的粒子，减少动态开关即时生效，暂停冻结世界。当前没有使用生图素材。
