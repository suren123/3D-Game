# 小车忙忙镇 V2 玩法

核心循环是「看图听任务 → 点记住了 → 选车 → 点图装货 → 选地点 → 点货格交货 → 得到反馈」。面向4–6岁儿童，每局三次委托，完成后可以休息或换一个小镇。

## 记忆与难度

- 轻松：一种物品、一个地点，一至两件。
- 记忆：两种物品、同一地点，各一件。
- 配对：两种物品、两个地点，各一件，先去哪边都可以。

三个难度使用同一套操作，设置内明确选择，不随错误次数暗中升级。任务卡用逐件图片和真实建筑图表达需求，同种物品两件也画两张；完成一件就在对应图片上打勾。物品名称优先两字、最多三字，与语音一致。任务页没有乘号、数量数字或分数。

主动点“记住了”才收起任务，没有倒计时。之后货架和目的地图卡不标正确答案；“再看”“再听”免费。提醒语音只说剩余任务及数量，不用先后顺序词强迫两站排序。所有语音为预生成本地片段，游玩时不联网合成。

## 选车与货格

保留十种不同外形、能力的车辆。每次最多给两辆符合任务且能一次装下的小车；只有冷藏车适用时允许单选。容量画成空格，最多两行三格，不写“能装几份”。货架有三至四种大图片，包含任务物品和干扰项。

点货架装一件，图从货架飞入空格；点已装格放回一件，图飞回货架。去除某格不移动其他货物，新增物品填空格。装货、选地点、驾驶和交货的格位一致；行驶时只读，到站点格交货。物品不堆在3D车顶。满载或交错物品只给温和提示/回弹，不假装成功转移。

## 地点与恢复

右侧最多四张大建筑图卡，包含本次全部目标和干扰地点。直接点3D建筑与点卡走同一规则。选了错误地点或已经完成的地点，在开车前提醒，车辆留在原处。空车不能出发送货，回仓库恢复始终允许。

携带错误或不够的物品仍可以到正确地点；到站明确显示“缺货啦”，货物保留。到站页一直提供“换地点”“回仓库”和“再看”；行驶中不提供无法兑现的换地点入口。错误交货不消耗物品，不扣分、不倒计时、不清零。

默认关闭自动修路、补货、载量变化与维修事件，避免与记忆训练同时引入多套操作。历史事件处理保留在代码中，不作为当前默认玩法或验收范围。

## 小镇与表现

同局地点道路固定，换局生成新种子；九个地点、三种主题、四乘四街区，地图与装饰随机独立于任务随机。保留现有Kenney玩具风格和真实3D场景，固定斜俯视近景平滑跟车，到站看见车和建筑，不要求儿童操作摄像机。

全Canvas独立右侧操作区，大图优先、短标签辅助。轻柔粒子表达点击、起停和交货，减少动态开关立即生效；暂停、转屏、帮助及图鉴不会重复增减货物。设置图鉴保留实际模型来源与缩放；成人来源说明不受儿童短标签约束。
