# Kenney 道路与街边装饰

本轮只接入本机库 `/workspace/kenney-3d-library/2026-11-12` 中精选的10个GLB。City Kit Roads 2.2提供5种道路及路灯、施工围栏、锥桶；Coaster Kit 1.0提供长椅、花卉。原始PNG已嵌入GLB；不改原始几何、UV、配色、材质和节点变换。来源、原模型/纹理SHA256、分发SHA256和完整原版许可证保存在 `public/models/kenney-streets/licenses/`。重建：`python scripts/import_kenney_streets.py`。

## 拼接规则

- 原版 `road-straight` 沿X轴。所有选中路口为1×1，弯角现选原版 `road-bend`，保留圆弧路缘和圆弧中心线；不把2×2的 `road-curve` 塞进1×1路口。
- **实际加载根变换是反射X，不是单独反射Z。** Babylon 9.35默认左手场景的glTF `__root__` 同时使用四元数 `[0,1,0,0]`（绕Y轴半圈）和scale `[1,1,-1]`，完整矩阵把源 `(x,y,z)` 变为 `(-x,y,z)`。AssetContainer克隆保留这两个变换。实际加载后开口：直路±X、尽头-X、圆弯+X/+Z、丁字±X/+Z、十字四向。`planStreets()`按真实 `map.edges` 匹配15种非空连接组合。
- 旧文档/测试仅按反Z重放，导致尽头、街角、丁字的canonical方向错误半圈；直路/十字的对称性掩盖问题，几何区间连通测试不能发现实际路缘封路。当前已经用真实Babylon loader根矩阵和加载后的路面三角形重新验证，不能引用旧反Z测试作为朝向证据。
- 节点各占一块3.75×3.75路砖；边段只填两个节点占地之间的空隙，接缝不重叠。当前10.5/11米节点间距会把中间两块直路各缩成3.375/3.625米长，即原等比例长度的90%/96.7%；宽、高不变，路面/路缘断面能平齐。原版直路中心线连续，并非旧描述中的虚线。此长度压缩和圆弧朝向问题不同，不是封死路口的根因。
- 原版直路可行车道宽占路砖80%，3.75总宽保留3.0米车道。现有2.5米车辆转弯半径保持不变，完整车身包络通过真实圆弯路面/路缘检测。圆弯视觉中心线半径约1.875米，不能为了让车跟线而直接缩小车辆转弯半径：长车会擦过实际路缘。
- 原版路面Y=.01、路缘Y=.02。路砖基准Y=.1625，缩放后路面正好Y=.2，与既有车轮基准一致。

## 街边布置与生命周期

长椅、花卉、路灯只在少量道路中点外侧的空地布置，避开已放地标及住宅。使用原版木色、橙白/金属色，未加自制替代外观。施工事件使用真实围栏与两个锥桶；事件解除及时销毁。所有街道与装饰都复用已预加载容器的 `instantiate()`，加入现有地图实例清理，不发新网络请求；子网格不可拾取，避免抢地点触摸。

原程序box路肩/路面/虚线、圆盘路口、box斑马线、程序围栏/锥桶已去掉。植被继续使用现有Kenney自然模型，农田原bush改为已加载的Nature `hedge`。外围植被按完整道路、地块和步道避让；停车场沿街步道宽度、住宅花盆位置也纳入实体几何回归。

## 验证

`tests/street-layout.test.js` 通过真实 `LoadAssetContainerAsync` 读取分发GLB，仅移除材质/图像绑定以避开Node缺少的图片解码器；几何buffer、节点、完整root矩阵均保留。测试测量实际路面覆盖，不再用“没有路缘”代替“道路开口”：圆弯封闭方向可能是空白草地，同样不能视为可通行路面。TypedArray索引通过 `Array.from` 转换，避免`.map`把Vector3强制变成NaN造成空检测。

道路回归包括：实际加载后的5类canonical开口及根矩阵、全部15种节点组合、1000地图无缝边段、8/9/10.5/11米间距的左右转弯。整车验证将实际拼装路面三角形与两组保守车身矩形（半宽/半长0.9/2.05和1.05/1.7米）比较，检查车身角点/内部路面覆盖，并用凸多边形SAT确认完整矩形不碰实际raised-curb三角形；不是只测汽车中心线或理想十字走廊。

`tests/world-placement.test.js` 同样改为真实loader加载全部模型，在32种子中检查实际建筑/住宅/停车车的地块边界、完整宽度步道和装饰净空、真实围栏三角形中央通道。修正loader约定后，额外独立重测0–199种子：上述地块越界、步道车道相交、植被车道相交、装饰入口冲突及围栏阻挡均为0；这次测量不沿用先前错误反Z重放的结论。

真实浏览器的修复前近景已复现seed19街角/丁字被路缘封闭，实际GPU顶点测量也独立证实旧方向差半圈。修复后的同角度截图和实际驾驶仍由主Agent复验；Node几何通过不替代视觉验收，云端软件渲染不代表iPad真机性能。
