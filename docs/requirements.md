# V2 需求记录

用户已确认：4–6 岁儿童、iPad Air 4 横屏、卡通低多边形明亮玩具感，点击和大按钮，固定斜俯视真 3D，不需要复杂摄像机控制。用户明确允许引擎、Kenney 资源、原创可复用模型及必要时生图。

本轮目标：完全 Canvas 游戏界面；随机地图和委托、更多物品与车辆；记忆与可恢复挫折；开始前全部资源准备好；更大的文字、热点和沉浸场景；轻量起停、天气、点击与庆祝粒子。用户另反馈旧版电脑 Chrome 卡顿，性能纳入交付检查。

## 实施范围

- 6 车 / 12 物品 / 6 模板 / 3 地图主题 / 4 可恢复事件。
- 三档显式难度；每局三单、一局内地图稳定；无隐式升难度。
- 孩子主动收起任务卡后，不能持续显示正确答案；自主选货、目的地和交货物品，免费再看与重听。
- 错误选择不扣分不销毁货物；缺货有备用来源，装不下可分批，封路始终可达。
- 按约定使用 Babylon.js + GUI；世界与 UI 一张可见 Canvas。WebGL 创建失败时允许 HTML 故障提示。
- 当前版本资源开始前下载、解析、解码、预热；之后断网玩和换图不能新增资源请求。不要求关闭页面后离线重开。
- 1180×820 逻辑布局、大字号与大按钮；暂停、背景切换、长按、拖出、取消、多指不得意外完成任务。
- 云端真实浏览器验证，至少 1000 种子规则检查；真实 Air 4 性能与儿童体验不能伪称已经通过。

## 设计目标与未验证部分

目标稳定 30 FPS，像素比上限 1.25；场景合批、资源共享、粒子有界。目标值不是测量结论。用户电脑硬件、iPadOS 版本以及目标设备实际帧率尚未取得；仍需用户试玩。
