# 游戏需求记录

## 用户已确认

- 为 4–6 岁儿童开发汽车主题网页游戏，首要设备为 iPad 横屏。
- 2.5D 斜俯视，卡通、低多边形、明亮、玩具感。
- 围绕“小镇 + 汽车任务”，尽量只用点击与大按钮，无复杂摄像机控制。
- 弱化失败惩罚，强化正向反馈；先给玩法、场景、交互方案，再生成可运行原型。
- 仓库 `suren123/3D-Game`；主 Agent 负责选型。本轮用户已授权从文档阶段进入实际开发。

## 原型采用的设计默认值

- 名称：小车忙忙镇；单人、纯前端、没有账号和服务器存档。
- 三个两步任务：送面包（面包店→公园）、送小花（花房→消防站）、洗洗车（洗车屋→车库）。
- 点击目的地或出发按钮，汽车沿道路自动驾驶；到站点一次大按钮完成帮忙动作。
- 不计时、不扣分，不存在失败或复杂碰撞；目标之外的地点可自由探索。
- 完成任务获得唯一贴纸；本机存储贴纸，存储不可用时仍可游玩。
- 固定相机、大触控目标、图标加短中文，可选声音提示；竖屏提示横放但不锁死页面。
- 用户推荐 Kenney 的 3D、UI 和声音资源，授权按适配性选用；原型采用其黄色汽车与短音效，建筑保持程序几何。素材按实际用途置于 public，不建立无用占位目录。

## 原型验收

- 启动后看见完整小镇、汽车、当前任务及大按钮；无强制注册和阅读教程。
- 三个任务的六步均可通过真实点击和行驶完成，贴纸不重复累计。
- 移动中重复点击不跳步；暂停冻结行驶，继续后恢复；重新选择任务不会错误领取奖励。
- 贴纸册、帮助、声音开关、任务选择可用；重载保留已获贴纸。
- 检查 1024×768、1180×820、1366×1024 横屏及小尺寸退化布局；记录浏览器自动化结果。
- 真实 iPad Safari 的触控、音频策略、GPU 性能和儿童体验另行验证，不能用云端模拟代替。
