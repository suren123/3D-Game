# Toy town models

Original low-poly models generated by this project with `node scripts/generate_models.mjs`.
All shapes are original geometry, using no downloaded textures or fonts. GLB 2.0, Y-up, ground at Y=0; building fronts face -Z; bus and tanker fronts face +Z.
Buildings are approximately 3–4 units wide and trees 3 units high. Meshes are merged by material.
Material colours are embedded linear RGB, with zero metallic and full roughness.
The files are reusable offline resources, not generated in the browser.
